# Fonts

Rubik, Fredoka and Varela Round, from Google Fonts. All three are licensed
under the SIL Open Font License 1.1 (https://openfontlicense.org), which
allows bundling them in the app.

Rubik covers Latin, Hebrew and Arabic. Fredoka and Varela Round cover Latin
and Hebrew; other scripts fall back to Rubik or the phone's own fonts.

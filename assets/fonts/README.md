# Fonts

Frank Ruhl Libre (headings), IBM Plex Sans Hebrew (text), Rubik and Fredoka,
from Google Fonts. All are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling them in the app.

Frank Ruhl Libre and IBM Plex Sans Hebrew cover Latin and Hebrew. Rubik
covers Latin, Hebrew and Arabic and is the fallback for any letter the others
lack. Fredoka is used in the check-off animations.
